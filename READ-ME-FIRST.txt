Muse CLI GUI v2.5.2 (Windows)
=============================
1. Unzip this folder anywhere.
2. Double-click MuseCLIGUI.exe.
   First launch: Windows SmartScreen may ask - choose More info > Run anyway.
3. The bridge starts, then the GUI opens in your browser.
Keep the bridge window open while you use the app.
Bonus: the bridge also serves an OpenAI-compatible API for OpenCode
at http://127.0.0.1:8766/v1 (key in Inspector -> More -> API access).
